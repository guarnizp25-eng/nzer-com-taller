# NZER.COM — Taller de desarrollo

Repositorio de trabajo para la web pública de NZER. No almacenar información sensible de menores, expedientes, contraseñas ni credenciales.

## Flujo de trabajo
1. Preparar modificaciones en GitHub y registrar los cambios en el historial.
2. Comprobar una vista previa antes de publicar.
3. Publicar en Netlify solo versiones aprobadas.

## Próximo objetivo
Rediseñar la portada de Inicio con colores vivos de NZER y fotografías ilustrativas de actividades infantiles; mantener independientes CARE, Desarrollo Infantil, PSICO y STORE. Los avatares originales solo se incorporarán cuando estén disponibles los archivos autorizados.
